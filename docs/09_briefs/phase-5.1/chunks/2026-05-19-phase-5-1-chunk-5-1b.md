### Task 2 — paymentService.record() implementation

**Files:**

**Implementation pattern:**

Function body operations sequence:

1. **Zod parse** via RecordPaymentInputSchema (Layer 2 boundary). On parse failure: `throw new ServiceError('READ_FAILED', ...)` with Zod message.
2. **Log + adminClient setup** (`const log = loggerWith({...}); const db = adminClient();`).
3. **Load bill** via `db.from('bills').select(...).eq('bill_id', ...).single()`. On not found: `throw new ServiceError('NOT_FOUND', ...)`. Verify org membership via parsed.org_id === bill.org_id (defense-in-depth; RLS catches separately).

5. **Validate referenced entities** (fiscal_period_id + ap_control_account_id + cash_account_id exist in org via existing `loadFiscalPeriodOrThrow` / `loadAccountOrThrow` helpers if exported from billService; OR inline duplication for paymentService).
6. **Compose payment JE** (Dr ap_control / Cr cash; single-currency CAD per Sub-L). Money helpers (`toMoneyAmount` / `toFxRate` / `zeroMoney`) canonicalize string shape per INV-MONEY-001 boundary discipline.
7. **Delegate to journalEntryService.post()** (Reading B preserved):
   ```typescript
   const { journal_entry_id } = await journalEntryService.post(
     {
       org_id: parsed.org_id,
       fiscal_period_id: parsed.fiscal_period_id,
       entry_date: parsed.entry_date,
       description: `Payment for bill ${parsed.bill_id}`,
       source: 'manual',
       lines: [drLine, crLine],
     },
     ctx,
   );
   ```
8. **INSERT payments row** (payment_purpose='bill_payment', payment_state='paid', applied_to='bill', vendor_id=bill.vendor_id, payment_method=parsed.payment_method, payment_date=parsed.payment_date, reference_number=parsed.reference_number, amount=parsed.amount_cad). On failure: `throw new ServiceError('POST_FAILED', ...)`.
9. **INSERT bill_payment_allocations row** (org_id, payment_id, bill_id, amount_cad, created_by, trace_id). On failure: `throw new ServiceError('POST_FAILED', ...)`.
10. **Emit `payment_recorded` audit** via recordMutation (or direct INSERT into audit_log mirroring billService pattern; verify at impl-onset which path billService.recordPayment uses for `bill_payment_recorded` audit).
11. **Dispatch T2_new_payment trigger** post-commit per Pattern B external-wrap variant + P3-i F-J-4:
    ```typescript
    try {
      await dispatchTrigger(
        {
          trigger_type: 'T2_new_payment',
          org_id: parsed.org_id,
          payment_id: payment.payment_id,
          vendor_id: bill.vendor_id,
          bill_id: parsed.bill_id,
          trace_id: ctx.trace_id,
        },
        ctx,
      );
    } catch (dispatchErr) {
      log.error(
        { err: dispatchErr, payment_id: payment.payment_id, trigger_type: 'T2_new_payment' },
        'T2 dispatch failed post-paymentService.record (best-effort; not propagating)',
      );
    }
    ```
12. **Return** `{ payment_id, journal_entry_id }`.
