## §3 — Rationale

### §3.1 Multidimensional retro evidence beats monodimensional consecutive-firing

Driver 2's actual question is "what evidence base does retro grade most need to adjudicate canonical Phase 8 cycle shape?" — not "which path is operationally best." Session 52's choice adds an N to the banking count + accumulates empirical evidence; the convention itself codifies at Phase 8 retrospective Commit A T3 amendment grade per Finding I banking inheritance from Session 50.

- **Path A fires** → 3 consecutive interleaved firings (Sessions 50+51+52). Monodimensional evidence — confirms pattern fires consistently but doesn't compare to alternative.
- **Path B fires** → 2 interleaved firings + 1 deliberate sequential test. Multidimensional evidence — retro grade has comparative empirical evidence to adjudicate which posture serves Phase 8 best.

Codification decisions deserve comparative evidence. Path B generates it; Path A doesn't.

### §3.2 Asymmetric premature codification risk

Convention-substrate-amendment cost is asymmetric:

- If interleaved gets codified at retro grade (Path A's N=3 routing) and future phases need to revert, that requires explicit ADR amendment OR convention-substrate amendment at Commit B grade — **high friction**.
- If interleaved stays at N=2 promotion-threshold-met but NOT graduated (Path B preserves this state), future phases can either consolidate the pattern (additional confirming-fire) OR deviate (sequential firing) **without convention-substrate amendment friction**.

Path B preserves codification optionality at low cost. Path A locks codification at potentially-premature timing without alternative-posture evidence.

### §3.3 §9.5 as authored hypothesis worth testing

Cycle-close §9.5 table at lines 587-604 (commit `e413b80`) authored sequential framing as the planning default at scope-lock-cycle close. Sessions 50 + 51 fired interleaved partly per §6.1 substrate-dependency rationale + partly per chunk 1 brief line 7 framing.

At Session 51 grade, the framing was "§9.5 table is stale; interleaved is canonical per §6.1." Reason 3 reframes §9.5 as authored-plan-worth-testing rather than stale-doc-substrate. §9.5 represented deliberate brainstorming-side + WSL-side joint thinking at scope-lock-cycle close; treating it as a hypothesis warranting empirical testing — rather than as stale artifact requiring T3 amendment — is methodologically honest at convention-substrate composition grade.

Whether interleaved beats §9.5 sequential is an empirical question the retro should answer. Path B gives retro the data it needs.
