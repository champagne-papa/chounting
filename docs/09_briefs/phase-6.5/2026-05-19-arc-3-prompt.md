STEP 2: GRADUATION EVALUATION (the judgment-heavy core)

For each family at N≥3, make the graduation call. This is not mechanical —
each family is a small ADR-shaped decision: does this pattern *deserve* a
convention file, or is it a useful tag that doesn't need promotion?

The decision framework, from the codification routing in CLAUDE.md and the
codify-convention skill:

  - N≥3 surfaces a candidate but doesn't mandate graduation.
  - Promotion is warranted when the pattern is *load-bearing* (future work
    benefits from naming it explicitly) AND *generalizable* (the convention
    file would be cited beyond the current arc) AND *stable* (the pattern
    has settled enough that the convention won't immediately need
    amendment).
  - Dismissal is warranted when the pattern is *narrow* (specific to a
    one-time situation), *unstable* (still evolving, premature to codify),
    or *captured-elsewhere* (the same insight already lives in an existing
    convention under a different name).

For each N≥3 family, surface:
  - The family name and instance count
  - The shared pattern across instances (one sentence)
  - The load-bearing / generalizable / stable assessment
  - Recommendation: GRADUATE, DISMISS, or DEFER (with reasoning)

Wait for my decision per family before invoking codify-convention. Don't
batch — each call is mine to make.
